## 通用导入方法

1. 打开表中对应功能卡，选择 API。
2. 打开预设的 `.curl` 文件，复制**完整内容**到请求示例框，点击「识别并导入请求」。这里把命令当作数据解析，不需要运行终端命令。
3. 核对应用 ID、输入用途和输出选择。填写自己的 Key；示例中的 `${RUNNINGHUB_API_KEY}` 只是占位，不是可用密钥。
4. 给工作流起一个名称，保存。切换已保存工作流后同样需要保存才生效。
5. 先做一次小样本测试，核对本次任务实际使用的应用 ID、生成结果与发送回执。

唱歌也支持把对应 `.json` 整份粘贴到节点参数框；它包含应用 ID。图片和视频优先用完整 `.curl`，不要只复制几行节点值。`catalog.json` 是目录，不是可以直接覆盖 `settings.json` 的配置文件。

## 音色参考：只需准备一次

随包文件是 [Breeze 普通说话参考](../assets/voice-presets/breeze-speaking-reference.wav)，时长约 **11.568 秒**，参数与校验值见 [reference.json](../assets/voice-presets/reference.json)。

- **RunningHub 翻唱**：在唱歌配置里用「上传参考音色」选这个 WAV，等待上传返回素材名，再保存为默认参考音色。每个人都用自己的 Key 上传；不要复制作者旧的 `api/…wav` 名字。
- **Breeze 语音**：配置示例沿用当前服务地址、模型、语言、引导强度和速度，并提供作者当前的音色 ID。该 ID 是否能被其他账号调用尚未验证。如果服务拒绝访问，用 WAV 在自己的服务账号创建或导入音色，再填写自己的 ID；插件本身不替你创建 Breeze 音色。
- **换音色**：上传新文件、核对参考截取长度后保存。换 Key 或账号时重新确认上传素材与音色权限。

Breeze 配置示例的 Key 为空，需要在语音页面填写。配置示例是字段对照，不能当 RunningHub 节点数组粘贴。语气由上下文和本句动态生成，不要把一种固定情绪写死到全局音色说明。

## 当前翻唱的节点

| 节点 | 用途 |
| --- | --- |
| `1.audio` | 本次原曲 `{{song_audio}}` |
| `2.audio` | 默认参考音色 `{{reference_audio}}` |
| `5.value` / `6.value` | 参考音色开始和结束秒数；随包文件预设取 0～11 秒 |
| `10.value` | 参考音色人声分离 |
| `37.value` | 波形动画，默认关闭 |

音色截取范围不是歌曲生成长度。聊天要求“只试前 30 秒”时，插件应先裁剪原曲，再按实际上传片段执行；不要把参考音色的结束时间改成 30 秒。新换的音色若不足 11 秒，需要同步调整参考范围。

备用流程的 **23 是音色、45 是原曲**，57 为原曲裁剪范围，58 为音色裁剪范围。导入器会设置 46 混音输出和第 2 个音频结果；更换到其他流程不能照搬这组输出节点。

不要在模板里预填固定原曲或默认歌名。点歌时先核对真实素材与库存身份；有已确认且匹配的版本可复用。没有新素材时不应随便生成或把同一段库存冒充另一首歌。库存里跑调、错歌的条目应删除或停止复用。

## 图片与视频的输入

图片应用需要两张真实输入：470 是待编辑图、475 是第二参考图，489(value) 是提示词；默认一张结果、9:16、分辨率档位 2。`{{image_1}}`、`{{image_2}}` 是任务输入占位，**不是 RunningHub 上已有的素材**，也不是可以直接提交的文件名。需要在图片设置的参考图映射中配置，或替换为自己上传取得的素材名。不要把双图编辑应用当成无需素材的文生图应用。

视频应用已在插件接入：181 是主人物参考图，216 是动态脚本，218 是时长，172 是画幅。预设 10 秒、9:16；实际任务可按支持范围调整。其他图片节点由现有适配器准备占位图，不能把 `{{neutral_image}}` 当作平台素材名直接执行 cURL。界面导入读取应用、时长和画幅，不宣称已导入全部分辨率或放大设置。

人物参考图由使用者提供；模板不含作者的私人头像或角色图。视频按动态脚本生成，不能用“提示词写了 10 秒”代替真正的时长参数。视频通常更贵，先检查设置再生成。

## 测试与排错顺序

先试听一句语音，再做短原曲翻唱，接着单张图片，最后视频。每次核对实际应用 ID、输入身份、输出文件和 QQ 发送回执。出现超时或结果不明，先查原任务 ID，不要立即重复提交收费任务。默认语音和翻唱通过语音消息发送；明确要求文件时才按文件发送。
