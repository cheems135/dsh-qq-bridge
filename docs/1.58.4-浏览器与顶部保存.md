# 1.58.4 固定浏览器程序与顶部保存

- 电脑版“自主操作设备”新增“固定浏览器程序路径”，默认使用用户指定的 `C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`。可以改成其他实际存在的浏览器 EXE；留空恢复自动发现。填写固定路径时只尝试该程序，失效时说明路径错误，不换用其他浏览器。
- 路径在本地模型与 API 工具间共用，不交由模型猜测。更换路径后，下次浏览重开插件自己的会话，沿用持久登录资料；不退出用户手动打开的浏览器。手机界面不显示 Windows 程序路径，并清除迁入手机的电脑版路径。
- 重复打开当前视频时保留实际页面和播放进度，兼容已知重定向与 B站跟踪参数。更换视频、分P或明确指定新时间仍可导航。自动刷新快捷键在刚加载的视频页面上至少间隔60秒，用户明确要求刷新不受此保护限制；没有增加聊天或任务次数配额。
- 模型浏览提示改为优先原地观察、等待、播放和滚动，避免为连续观察反复导航、刷新或关开浏览器。
- 顶部新增常驻“一键保存”，提交当前页面能够识别的设置修改；分别使用现有保存接口，显示未保存、提交中、成功或失败。失败保留输入；不触发试听、生成、消息发送或发布操作。跨页面草稿、需要专门按钮的操作仍按原入口处理，不声称全部保存。
- 整体模式和 API 补充修改后明确提示尚未应用；补充本地语音、整体模式与连接配置的保存状态追踪。本地能力检查保留接口失败原因，避免只剩笼统的“本地服务不可用”。

本次实际电脑检查：插件运行1.58.3，本地网关仍运行1.52.1且可连接ComfyUI；本地聊天及API补充原本均关闭。已通过实际设置接口将本地聊天设为开启、API补充设为关闭，并读回确认。用户将稍后自行配置非DeepSeek的备用API，本次未调用任何聊天或生成模型。

验证：715项自动测试通过；指定浏览器、失效不回退、路径切换保留配置、重定向页面复用、B站视频定位及刷新保护均使用模拟浏览器验证；桌面/手机宽度检查顶部保存和失败草稿保留，手机隐藏PC路径；两端隔离启动无网络请求。没有实际浏览视频网站、发送QQ消息、运行视频生成或调用生成模型。

安装仅替换源码，保留设置、聊天和记忆；不自动重启DSH或本地网关。重启后加载1.58.4插件；本地网关仍需用户在空闲时自行重启以加载此前1.58.3更新。手机版文件准备不等于已经写入实际手机。
