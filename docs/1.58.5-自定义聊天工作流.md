# 1.58.5 自定义本地聊天工作流

- 在本地聊天工作流选择器旁新增“导入自己的聊天工作流”和“使用选中的聊天工作流”；自定义工作流优先显示，原三个预设保留为快捷项。工作流库里的每个聊天项目也可直接用于本地聊天。
- 导入后可勾选直接用于聊天，由网关一次保存工作流和选择，桥接同步实际 backend、chatWorkflow、modelId。没有自动改动整体本地/API模式，也没有打开API补充。
- 完整开放用户输入、人设/系统、对话历史、请求编号、多模态图片、温度、回复长度及输出节点/字段映射；更改名称或ID时同步选择。顶部保存支持工作流编辑草稿。
- 聊天专用导入优先识别文本分支，混合图像/聊天工作流只保存选中输出的祖先节点。API工作流也可读取节点定义辅助识别；无法自动识别的文本回执可手动指定，仍校验节点存在和输入依赖关系。
- 没有独立人设、历史输入时，将必要上下文合并进用户文本，避免静默丢失人设和上下文；独立映射存在时保持原传参。重复映射同一字段会说明问题。
- 自定义聊天只从指定节点、指定文本字段读取回复；空回执、对象回执或错误字段会报出映射问题，不把其他节点的模板文本当答案。不提交无关生图分支，不为没有请求ID映射的工作流启动Qwen专用流式轮询。
- 通用聊天工作流没有Qwen节点时，不强制执行Qwen专用卸载图，使用标准ComfyUI释放接口；此前实际使用过Qwen的轮次仍保留专用清理。8GB配置与串行队列继续保留，未知节点的模型规模、显存与输入协议仍由所选工作流和ComfyUI插件决定。
- 网关和插件未加载更新时，自由聊天导入入口会说明需要重启，不把旧进程忽略新参数当作成功。

验证：720项自动测试通过；模拟完整HTTP导入/保存/选择，实际Comfy运行函数向模拟服务提交自定义模型与人设历史、裁剪无关分支并验证文本回执；浏览器检查自定义选择、全部映射编辑、手动回执和底部保存；两端隔离启动无网络请求。没有调用真实聊天/生成模型、执行视频生成或发送QQ测试消息。

安装仅替换源码，保留设置、聊天和记忆，不自动启动/重启DSH或本地网关。用户需自行重启DSH，并在没有任务运行时执行工具脚本 `start-local-ai.ps1 -Restart` 加载1.58.5网关；脚本会检查当前任务，忙碌时保留任务。实际手机不支持本地推理，保存的手机版保留API逻辑。
