# 1.59.1 · 全面检查与连接稳定性

本轮以现有功能和用户设置为基础检查，合并公开仓库 1.58.5 之后的修复，并更新 README。没有替换用户人设、改变聊天模型、自动启用 API 补全或重启服务。

## 本轮修复

- 同一连接的局部更新保留未修改字段：只更换聊天模型时，图片模型、参考图编辑模式、语音模型/音色、视频模型和接口路径不重置；显式清空仍生效，跨站点密钥校验保留。
- 本地网关仅在配置文件不存在时使用空白初始配置。已有文件的 JSON 或字段无效时说明问题并保留文件，不悄悄切回默认模型或覆盖原配置。兼容 BOM 编码。
- 指定浏览器的后台/可见窗口切换会先保存当前身份的 Cookie，再交给新窗口；不跨账号/人设复制，不退出用户手动打开的浏览器。仅验证 Cookie，不承诺所有网站的其他登录存储都可迁移。
- 短链接跳到实际视频页后，续看会保存最终页面地址，避免同一暂停视频被误认为新视频而重新播放。
- 修复普通照片搜索的未定义域名常量。此功能先用本地图库，再搜索网络实拍图片；与人设参考图、AI 生图分开。图库域名只参与质量排序，其他来源仍可使用；按实际主机名匹配，下载过程限制字节数。

## 本次同步到公开仓库的既有修复

- 自定义本地聊天按输入、输出映射传输；不预选模型，保留用户工作流中的模型与服务地址。支持可选布尔图片开关。
- PC 普通视频与 B站观看使用固定浏览器；后台优先、暂停、定位和实际画面回执。手机保留 API 和本机媒体读取。
- PC 窄窗口导航、表单、长路径、浮窗和嵌入面板高度适配；PC 与手机界面保持独立。
- 已选定的人设参考图不能被聊天模型省略或替换；图像主体规划缺失时先确认，不提交无参考图替代。记录区分配置、选择与实际绑定。

## 验证与限制

748 项自动测试通过。128 项页面/宽度检查无横向溢出，PC 与手机隔离启动通过，真实 Edge 本机视频测试页面通过。测试包含模拟提供商、ComfyUI、工具和发送回执，不等于线上平台全量实测。

没有真实模型推理、生图/视频生成、收费 API 调用、QQ 消息发送或空间/B站评论。没有检测到连接手机，因此没有实际手机安装或设备操作验证。源码版手机同步更新，仍只支持 API。

用户此前要求暂不修改的 Live2D 情绪变量问题保留。图像画风、语言理解和每项细节不能由传输测试保证；参考图连接成功只证明输入已绑定。8GB 对未知节点与独立外部服务不作容量承诺。

安装后需用户自行重启 DSH；本地网关需在空闲时运行 `tools/start-local-ai.ps1 -Restart`。保存的模型、登录、聊天、记忆、日程和用户图片保留。
