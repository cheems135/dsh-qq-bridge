# 重要功能与使用提示

[第一次使用](quickstart.md) · [API 与音色预设](api-workflows.md)

## 人设、学习与“人味”

人设影响关注点、判断和表达，学习资料与真实记忆提供依据；它们不是同一个功能。模型仍会误解、重复或输出不合适的句子，不能把加载了某份提示词等同于完全学会交流。

当前包内提供 6 组公开贴吧接话参考，相关时才取用，优先参考相处中学到的表达。它没有复制作者的私人聊天、个人记忆或运行人设卡。希望接近某个使用效果，需要自己设置关系、人设、模型及学习开关。

明确教过的表情含义应保留来源并在同一联系人后续交流中召回；不把一人的私有解释无条件传播到群聊。纠正时直接说明“这个表情在我们这里是什么意思”，然后到学习记录核对写入与应用。记录出现不代表已在那一轮成功用到。

普通聊天按真实换行分段，不使用 `|||` 或 `||` 作为控制符。默认直接说话，不附括号动作旁白；明确创作故事、引用或写代码时保留相应文体。图片、语音、翻唱等分享由语境与模型决定，不是每个关键词都强制生成。

语音情绪不局限于几个固定档位。插件按本句与语境准备演绎方向，但实际效果受语音服务和所选音色支持程度影响；情绪标签本身不是已经哭了、笑了或生气的证据，应以试听为准。

## 记忆的本体与备份

人格与记忆文件保存在插件设置显示的数据位置，QQ 是连接账号。换 QQ 不等于删除这些文件。不同联系人、群和来源仍有隐私边界；不能把“资料存在”理解为“任意对象都可以读到所有历史”。记忆管理按对话来源展示，历史人设记录保留来源，避免重复选择项。

换机器、更新、重装前备份设置中列出的数据、记忆和素材目录。手机和电脑要分别核对代码版本、连接与同步状态；同一套源码不代表两台设备的账号、上传素材或系统权限已自动一致。

## 日程、主动行为与费用

日程区分计划、执行和完成。她说“准备去做”不是任务已成功；执行状态、工具回执与作品文件才是依据。聊天可以先回应，耗时生成继续在任务链里执行，不应把所有聊天锁到媒体生成结束。

可以分别调整主动互动、实际日程、空间互动与各媒体来源。觉得吵时先调整主动互动和日程配置，而不是删除记忆。视频、图片、语音和翻唱的计费分别由相应服务决定；本地聊天搭配云端媒体仍会产生云端费用。

费用面板按已记录调用估算；模型思考、输出、缓存命中和辅助分析都可能影响花费。QQ 分成几条气泡不等于调用了几次模型。适当复用同一会话有利于缓存，但历史也不能无限堆积；插件会在合适时机整理并保留原记录。

## QQ、空间与工具

- **普通 QQ 与桥接连接**：QQ 登录、NapCat 接管和插件连接是三个环节。核对当前会话、进程和接口状态，不只看好友列表上的在线图标。
- **离线未读**：重连后只在已有权限和可取回的历史范围内补读；读取不到、未加入群或历史不足会影响恢复。不要为了补读直接清空已有会话。
- **QQ 空间与资料**：浏览、发布、评论、签名、头像等按当前账号实际能力和回执执行。接口显示在目录里不证明每项都受当前 QQ/NapCat 版本支持。
- **MCP 网站封装**：登录状态与浏览器资料目录、服务接口及目标网站有关。封装之后仍要测试账号身份和所需内容是否可读；仅打开公开首页不等于已保存账号。
- **陪看与视听**：画面、字幕、音轨的取得和理解是不同环节。一张截图不能证明听到了声音，转写文本也不证明识别了说话人的真实情绪。
- **手机识屏**：独立组件需要 Android 的安装确认、悬浮窗与屏幕共享许可。保护画面、系统限制或授权失效可能导致无法取图。
- **本地网关**：在本地功能页检查地址、状态、模型/ComfyUI 工作流与所选能力；另一台电脑的 `127.0.0.1` 不是你的手机本机服务。

自动延迟、冷却和重连不能保证 QQ 账号不会被平台限制。不要把接口不报错等同于连接长期稳定。

## 任务卡住、没回复或发错素材时

按“接收 → 模型 → 工具 → 生成产物 → 发送队列 → QQ 回执”逐步看同一个请求。生成成功但没送达，先看发送；歌曲不对，先查原曲身份和库存标签；改工作流未生效，查本次实际提交的应用 ID。

结果未知的任务不要盲目重试，避免重复发送、重复计费。空正文会做有限恢复，失败保留原输入和异常；它不该被一条固定占位话术伪装成正常回复。提出问题时保留版本号、请求编号、实际来源和错误阶段，隐去密钥与私人聊天。
