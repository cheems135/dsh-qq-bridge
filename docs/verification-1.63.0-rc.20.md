# 1.63.0-rc.20 发布核验

## 本版行为

- 学习资料按具体概念及来源检索，普通聊天可直接召回；同一对话的历史人设资料可继续使用，其他对话仅共享符合条件的公共知识。记忆管理按对话来源展示，保留原始来源和纠错能力。
- 媒体分享按人设、语境和实际能力选择；不添加特定语句必须发图的触发规则。转发中的超长图片生成受限的阅读副本，原图和其他消息内容保留。
- 普通私聊只返回思考、没有正文时，最多补一次纯文字回复；不重跑工具，不转发思考，不发送空回复占位提示。恢复失败保留原输入和明确异常，新消息或身份变化后不发旧结果。
- 普通聊天不写括号动作旁白；故事、引用、代码、正常括号和媒体参数保留。
- 上下文整理不再因为聊满8轮、增加8000 tokens，或单纯聊满40轮就换页。普通整理在明显增长且至少24轮后进行；接近所配置窗口容量时仍提前保护。原聊天与记忆保留。

## 验证结果

发布副本的完整测试共1614项：1613通过，0失败，1项既有可选环境测试跳过。272个JavaScript模块和5段内联脚本语法通过。空正文、动作清理与上下文接续的25项专项也在本机安装目录通过。

原始超长转发曾做只读核验，3条记录和2张图片均可读取；不等于已经完整核验模型对画面内容的理解。桌面安装版加载后核对了桥接与QQ登录在线；本次发布没有额外发送QQ消息、发布空间动态或生成付费媒体。

这些结果不能证明所有提供商工作流、手机设备或实际聊天场景均已通过。人设表达和媒体意图仍受模型输出影响；减少换页后的长期费用变化需要新的实聊样本验证。

## 发布与本机差异

功能源码来自同一候选版本。公开副本只将开发者电脑上的固定目录改为环境变量或通用路径，并清理行尾空白、更新文档；不包含聊天、私人记忆、运行人设卡、账号配置、登录凭据、模型权重或个人媒体。本机已安装配置与目录不被发布步骤改写。

本地媒体目录可用LOCAL_MEDIA_DIR，网关临时目录可用LOCAL_AI_WORK_DIR，启动辅助脚本的工作目录可用CODEX_DATA_WORK_DIR指定。可选虚拟空间使用PET_SPACE_CHAT_ADAPTER、PET_SPACE_RESIDENCE_ADAPTER、PET_SPACE_UNITY_HOME、PET_SPACE_HOME配置；适配器需要用户自行提供。
