# 1.58.3 本地语音连接、电脑版 QQ 登录与蓝白格手账

- 本地语音可选 VoiceLab、OpenAI 兼容语音、自定义同步 JSON 接口。支持本机与局域网地址、自选模型/音色、接口路径、参数模板及启动程序/工作目录。无需固定安装软件或 D 盘下载目录。
- JSON 模板支持 `{{text}}`、`{{voice}}`、`{{model}}`、`{{instruction}}`，返回支持直接 WAV、JSON base64、同站点音频 URL。只接受有效 WAV；不把错误 JSON 或 MP3 当 WAV 发出。不支持的软件私有多步协议需要额外适配，不能仅凭地址保证兼容。
- 音色接口可以留空并手填 ID。语音服务密钥可选，读取设置会遮蔽；留空保存保留原密钥，更换站点不继承旧密钥。更换连接不偷偷改用云端。
- 区分 CPU/GPU 语音。CPU 不主动卸载聊天模型；GPU 仍按 8GB 规则串行，缺少释放接口时给出具体说明，不假称已释放显存。
- 自定义启动程序只在用户运行本地启动脚本时执行；配置未完成时提示手动启动，不启动另一套 VoiceLab。原有未迁移配置可兼容旧安装目录，保存新设置后以新目录为准。
- 修复电脑版 QQ 登录状态必须先有机器人账号配置的循环依赖。可从已运行 NapCat 的已登录账号识别当前账号；未配置账号时也可显示二维码。账号不一致时不静默切换，不终止无法确认身份的 QQ 进程。
- 登录诊断区分“桥接未连接”与“端口未启动”，不再只依据旧二维码误报 QQ 注入失败。QQ 登录与设备接管仍分别管理；保留当前暂停状态，不自动恢复聊天。
- 私人手账改为浅蓝白交错格纹，电脑与手机分别适配，保留手写字体和日记内容。

验证：709 项自动测试通过；本地 HTTP 模拟服务验证语音请求与音频回执；电脑/手机隔离启动均无网络请求；浏览器检查语音配置捕获和两端手账样式；启动脚本语法与状态探测检查通过。仅只读检查了实际 NapCat 状态和当前已登录账号，没有真实发送 QQ 消息或调用聊天/语音/视频生成 API。

只安装源码，保留设置、聊天和记忆。没有自动重启 DSH/本地网关，也没有恢复 QQ 连接。需要用户空闲时自行重启加载更新。保存手机版目录更新不等于实际手机安装。
