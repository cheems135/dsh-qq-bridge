# 1.63.0-rc.21 教程与预设核验

本版补充首次使用、API工作流与重要功能说明，不改变正在运行的用户连接、私人记忆或人设配置。

## 本版资源

- 四份 RunningHub 请求：双图编辑、视频、当前翻唱、备用翻唱。每份提供完整 cURL 与含应用 ID 的 JSON。
- 一份 Breeze 语音配置示例；Key 为空。作者当前音色 ID 的跨账号调用权限未验证，教程提供使用参考音频创建自己音色的步骤。
- 一份维护者指定的普通说话参考 WAV，时长 11.568 秒、555342 字节，附 SHA-256。内容为普通日常话语，不包含歌曲库存和私人演出配方。
- 保留既有 6 组公开贴吧接话参考、来源和原创示例，并说明它不等于整库训练或复制私人记忆。

## 已做检查

完整测试共1619项：1618通过、0失败、1项既有可选环境测试跳过。新增5项检查覆盖实际请求解析、两套翻唱的音色与原曲绑定、音色WAV的真实长度与参考截取、凭据排除、教程链接与打包清单。

实际调用现有导入器检查了四份请求，使用虚构素材名渲染翻唱节点；没有向 RunningHub 提交收费生成。打包预检确认教程、请求、参考音频及原有测试需要的夹具均包含在包内。

语音文件已核对为普通说话参考；机器转写只用于发布前内容检查，不作为音色质量、情绪识别或克隆效果的证明。

## 尚不能保证的部分

这些检查不能证明应用始终在线、任意账号均有访问权限，或音准和人物一致性达到预期。Key、平台音色权限、实际原曲和图片仍由使用者提供；节点占位符不是平台素材。历史上未保存完整节点的应用不会被标为即用预设。
